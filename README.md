# Есть дефект или нет

Маленький скрипт на Python (Pillow), который по одной картинке определяет:
**OK** (норма) или **DEFECT** (брак).

## Файлы

- `ok.png` — тестовое изображение без брака (ровный зелёный квадрат);
- `defect.png` — тестовое изображение с браком (зелёный квадрат с большим
  красным пятном);
- `detect.py` — сам скрипт.

## Как запустить

```bash
pip install pillow
python3 detect.py ok.png
python3 detect.py defect.png
```

Можно передать любой другой файл (свою фотографию) и при желании
подстроить порог:

```bash
python3 detect.py my_photo.jpg --threshold 0.1
```

## Правило классификации

Модель не используется. Логика простая:
1. Переводим картинку в RGB.
2. Для каждого пикселя проверяем, является ли он «красным»: красный
   канал заметно (в 1.5 раза) больше зелёного и синего, и не слишком
   тёмный (`r > 120`) — это отсекает коричневые/тёмные тона.
3. Считаем долю таких пикселей от общего числа.
4. Если доля ≥ порога (по умолчанию **15%**) — печатаем `DEFECT`,
   иначе — `OK`.

## Результат на тестовых данных

| Файл | Доля красного | Результат |
|---|---|---|
| ok.png | 0.0% | OK |
| defect.png | 28.7% | DEFECT |

## Ограничения / как улучшить

- Порог и определение «красного» подобраны под простой пример с явным
  красным пятном на однотонном фоне — для реальных фото порог и правило
  цвета брака нужно будет подстроить под конкретный тип дефекта.
- При необходимости `red_ratio()`/`is_red_pixel()` легко заменить на
  вызов настоящей модели классификации изображений — интерфейс
  `classify(path) -> (verdict, score)` при этом не меняется.
